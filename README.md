
# Petshop Bigodes 🐾

## Projeto da disciplina Fundamentos de Sistemas Web – PUCRS

### 1. Apresentação

O Petshop Bigodes é um projeto acadêmico desenvolvido como atividade da disciplina Fundamentos de Sistemas Web. O sistema consiste em uma plataforma web de apresentação de produtos e serviços de um petshop fictício.

O objetivo é o de desenvolver uma estrutura de navegação e apresentação de informações utilizando HTML5.

### 2. Objetivo

Desenvolver um sistema web que permita às pessoas usuárias consultar produtos e serviços de um petshop, organizados por categorias, com informações sobre imagens, descrições e preços.

### 3. Produtos e serviços

O sistema apresenta três categorias de produtos:

- **Acessórios:** camas, brinquedos e outros acessórios.
- **Rações:** opções de alimentação para gatos e cães.
- **Higiene e Limpeza:** produtos destinados à higiene dos animais.

Também são apresentados os seguintes serviços:

- Banho e tosa sem tele-busca.
- Banho e tosa com tele-busca.

### 4. Estrutura do projeto

O sistema está organizado nas seguintes páginas:

| Arquivo | Funcionalidade |
|---|---|
| index.html | Página inicial |
| acessorios.html | Categoria de acessórios |
| racoes.html | Categoria de rações |
| higiene.html | Categoria de higiene e limpeza |
| servicos.html | Apresentação dos serviços |
| ajuda.html | Orientações de navegação |

A pasta `imagens` contém os arquivos utilizados na apresentação visual dos produtos e serviços.

### 5. Tecnologias utilizadas

- HTML5
- Visual Studio Code
- GitHub
- GitHub Pages

### 6. Orientações de utilização

A pessoa usuária pode navegar pelas diferentes páginas utilizando o menu localizado no cabeçalho ou os links disponíveis no rodapé.

Em cada categoria, são apresentados produtos com imagens, descrições e preços. Na página de serviços, são apresentadas as modalidades de banho e tosa, incluindo a opção de tele-busca.

### 7. Observações

Este projeto corresponde à Fase 1 da atividade acadêmica do referido curso. Nesta etapa, foi desenvolvida a estrutura das páginas utilizando HTML5, sem implementação de CSS, Bootstrap ou JavaScript, conforme instruções do exercício.

Os produtos, serviços e valores apresentados possuem caráter ilustrativo.
